完整页面

  • lm_head 与 NLL Loss：3D 场景、步骤条与面板。
  • Softmax 与交叉熵：单样本与批量两种模式。
  • Softmax 小部件：只用步骤条和面板，不加载 3D。
  • Qwen3 一层的前向与反向：从 token id 到损失，一个 decoder 层完整展开。页面代码按 HF 的模块层级写成嵌套函数，每个模块在场景侧面有一个大括号，相机跟随当前步骤。
  • Qwen3 一层：自动布局：建图代码与上一页相同，布局由 autoLayout 按模块层级生成，用来和手写布局对比。
  • Qwen3（YAML）：和上一页同样的模型与数值，用 qwen3/qwen3-dsl.yaml 页面描述文件写成，由 <vizflow-page src> 在浏览器里编译。
  • Qwen3.5（YAML）：Qwen3.5 的混合结构，第 0 层是 Gated DeltaNet 线性注意力，按块计算并在块之间传递状态；第 1 层是带输出门、只转部分维度 RoPE 的 softmax 注意力。用 qwen3_5/qwen3_5-dsl.yaml 写成，模型定义在包内的 src/models/qwen3_5/。
  • Qwen3 MoE 最后一层（YAML 页面描述）：Qwen3-30B-A3B 的最后一层，注意力和 Qwen3 相同，MLP 换成 softmax 路由、选 top-k 个专家的稀疏 MoE，没有共享专家。用 qwen3_moe-dsl.yaml 写成。
  • Qwen3.5 MoE 最后两层（YAML 页面描述）：Qwen3.5-397B-A17B 的最后两层，token mixer 与 Qwen3.5 相同，MLP 换成稀疏 MoE 加一个带 sigmoid 门的共享专家。用 qwen3_5_moe-dsl.yaml 写成。
  • Qwen3.8 Dense：Qwen3.8-27B 的结构和尺寸与 Qwen3.5-27B 完全相同，用的是 Qwen3.5 那一页。
  • Qwen3.8 MoE 最后两层（YAML 页面描述）：Qwen3.8-2.4T-A95B，结构与 Qwen3.5 MoE 相同，尺寸按它的 config。用 qwen3_8_moe-dsl.yaml 写成。
  • Qwen3.8-Flash-Next（YAML 页面描述）：HF 的 qwen4_exp 结构，从 token id 画到损失。残差流复制成几条并行的流，每个子层经过 GatedResidual 读出和写回；第 2 层有 PLE（n-gram 哈希嵌入）；full_attention 层的注意力前面有 QSA indexer，按块选出要保留的 key。用 qwen3_8_flash_next-dsl.yaml 写成。
  • DeepSeek V3：MLA 与 MoE（YAML）：两层，第 0 层是 dense 层，第 1 层是 MoE 层。注意力是 multi-head latent attention，q 和 kv 先压缩成 latent 再展开，带位置的一段做相邻分量配对的 RoPE；MoE 用 sigmoid 亲和度、按组限制的 top-k 路由和一个共享专家，每个专家只算选中它的 token。模型定义在 src/models/deepseek_v3/，页面只写配置与面板，见 deepseek_v3/deepseek_v3-dsl.yaml。
  • DeepSeek V3.2：DeepSeek Sparse Attention（YAML 页面描述）：和上一页的结构相同，每一层的 MLA 里多一个 lightning indexer，给每对位置打分，每个位置只保留分数最高的 index_topk 个 key 参与注意力。用 deepseek_v3_2-dsl.yaml 写成。
  • DeepSeek V4：压缩注意力与 mHC（YAML 页面描述）：第 3 层（CSA，hash 路由的 MoE）和第 4 层（HCA，top-k 路由的 MoE），尺寸按 DeepSeek-V4-Flash。注意力的 key 是滑动窗口里的 token 加上压缩过的条目，CSA 的 indexer 只挑出少数几个条目；残差是几条并行的 stream，由 mHC 在子层前合成、在子层后写回。用 deepseek_v4-dsl.yaml 写成。
  • DeepSeek V4.1：图片、Engram 与三种压缩注意力（YAML 页面描述）：一张小图片经过 ViT 和 aligner 变成图片 token，插进文字序列；第 1 层多一个按 n-gram 查表的 Engram；压缩注意力分成自己压缩并选条目的层、只在候选块里重新选条目的层和沿用别层结果的层，各展开一层，尺寸按 DeepSeek-V4.1-Flash。用 deepseek_v4_1-dsl.yaml 写成。
  • lm_head 与 NLL Loss（vizflow-page 元素）：同一页用 <vizflow-page> 元素写成，页面只给元素设置属性。

模块与写作说明的检查页

  • scene3d：lm_head 与 NLL Loss：只挂载 3D 场景。
  • scene3d：模块大括号与相机跟随：模块大括号的嵌套与错开，换步骤时相机跟随当前步骤。
  • scene3d：编辑模式：拖动块与标签，复制布局配置。
  • log_softmax 与 nll_loss 小部件：按写作说明独立写出的页面，用来检查说明是否够用。
  • theme：颜色变量与字体。

用构建工具的项目

examples/vite-project/ 是一个独立的 Vite + TypeScript 项目，从 npm 包的构建工具产物引用 vizflow，内容与 lm_head 页面相同。它要在自己的目录里安装和运行，步骤见其中的 README.md。
