完整页面

  • lm_head 与 NLL Loss：3D 场景、步骤条与面板。
  • Softmax 与交叉熵：单样本与批量两种模式。
  • Softmax 小部件：只用步骤条和面板，不加载 3D。
  • Qwen3 一层的前向与反向：从 token id 到损失，一个 decoder 层完整展开。页面代码按 HF 的模块层级写成嵌套函数，每个模块在场景侧面有一个大括号，相机跟随当前步骤。
  • Qwen3 一层：自动布局：建图代码与上一页相同，布局由 autoLayout 按模块层级生成，用来和手写布局对比。
  • Qwen3 一层（YAML 页面描述）：和上一页同样的模型与数值，用 qwen3-dsl.yaml 页面描述文件写成，由 <vizflow-page src> 在浏览器里编译。
  • Qwen3.5 最后两层（YAML 页面描述）：Qwen3.5 的混合结构，倒数第二层是 Gated DeltaNet 线性注意力，按位置展开状态的递推；最后一层是带输出门、只转部分维度 RoPE 的 softmax 注意力。用 qwen3_5-dsl.yaml 写成。
  • DeepSeek V3：MLA 与 MoE（YAML 页面描述）：第 3 层（最后一个 dense 层）和第 4 层（第一个 MoE 层）。注意力是 multi-head latent attention，q 和 kv 先压缩成 latent 再展开；MoE 用 sigmoid 亲和度、按组限制的 top-k 路由和一个共享专家。用 deepseek_v3-dsl.yaml 写成。
  • DeepSeek V3.2：DeepSeek Sparse Attention（YAML 页面描述）：和上一页的结构相同，每一层的 MLA 里多一个 lightning indexer，给每对位置打分，每个位置只保留分数最高的 index_topk 个 key 参与注意力。用 deepseek_v3_2-dsl.yaml 写成。
  • lm_head 与 NLL Loss（vizflow-page 元素）：同一页用 <vizflow-page> 元素写成，页面只给元素设置属性。

模块与写作说明的检查页

  • scene3d：lm_head 与 NLL Loss：只挂载 3D 场景。
  • scene3d：模块大括号与相机跟随：模块大括号的嵌套与错开，换步骤时相机跟随当前步骤。
  • scene3d：编辑模式：拖动块与标签，复制布局配置。
  • log_softmax 与 nll_loss 小部件：按写作说明独立写出的页面，用来检查说明是否够用。
  • theme：颜色变量与字体。

用构建工具的项目

examples/vite-project/ 是一个独立的 Vite + TypeScript 项目，从 npm 包的构建工具产物引用 vizflow，内容与 lm_head 页面相同。它要在自己的目录里安装和运行，步骤见其中的 README.md。
