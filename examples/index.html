完整页面

  • lm_head 与 NLL Loss：3D 场景、步骤条与面板。
  • Softmax 与交叉熵：单样本与批量两种模式。
  • Softmax 小部件：只用步骤条和面板，不加载 3D。
  • Qwen3 一层的前向与反向：从 token id 到损失，一个 decoder 层完整展开。页面代码按 HF 的模块层级写成嵌套函数，每个模块在场景侧面有一个大括号，相机跟随当前步骤。
  • Qwen3 一层：自动布局：建图代码与上一页相同，布局由 autoLayout 按模块层级生成，用来和手写布局对比。
  • Qwen3 一层（YAML 页面描述）：和上一页同样的模型与数值，用 qwen3-dsl.yaml 页面描述文件写成，由 <vizflow-page src> 在浏览器里编译。
  • Qwen3 一层，两张卡的张量并行（YAML 页面描述）：同一个 decoder 层按 Megatron 的张量并行切到两张卡上，柱子按所在的卡着色，Partial 画成两根细柱，工具栏可以切换训练、prefill 和 decode；下方的面板随步骤画出两张卡各持有张量的哪一部分，以及 all_reduce 在两张卡之间的环形传输和字节数。用 qwen3-tp-dsl.yaml 写成。
  • DeepSeek V3 MoE：4 张卡的专家并行：一个 MoE 层的前向，专家分到 2 个节点的 4 张卡上，按 DeepEP 的 hybrid 模式 dispatch 和 combine，数值和单卡的 MoE 相同。工具栏的「按卡分开」把计算图画成每张卡一份，只画这张卡上的数据，卡之间的传输画成按 NVLink 和 RDMA 着色的连线。用 deepseek_v3-ep.yaml 写成。
  • Qwen3.5 最后两层（YAML 页面描述）：Qwen3.5 的混合结构，倒数第二层是 Gated DeltaNet 线性注意力，按位置展开状态的递推；最后一层是带输出门、只转部分维度 RoPE 的 softmax 注意力。用 qwen3_5-dsl.yaml 写成。
  • DeepSeek V3：MLA 与 MoE（YAML 页面描述）：第 3 层（最后一个 dense 层）和第 4 层（第一个 MoE 层）。注意力是 multi-head latent attention，q 和 kv 先压缩成 latent 再展开；MoE 用 sigmoid 亲和度、按组限制的 top-k 路由和一个共享专家。用 deepseek_v3-dsl.yaml 写成。
  • FP8 Linear：块缩放量化（YAML 页面描述）：按 DeepSeek V3 的做法，激活按 1 行 b 列、权重按 b 行 b 列的块量化成 E4M3，画出缩放因子、码字、反量化值和量化误差，与不量化的矩阵乘对照，反向用直通估计器；每个节点的数值按自己的 dtype 舍入。用 fp8-linear-dsl.yaml 写成。
  • 推理调度：vLLM 与 SGLang：同一组请求按两个引擎的调度规则逐步推演，看连续批处理、分块 prefill、前缀缓存、抢占与撤回、CUDA graph 填充和重叠调度。两个模拟器与真实调度器在 CPU 上跑出的轨迹逐步一致。
  • 打包批次的注意力：推理引擎一步的单 head 注意力，几个请求的新 token 拼成一块，读各自的 KV cache，分块的因果 mask 让请求互不可见，只取每个请求的最后一行去算 logits。可以切换混合、只有 prefill、只有 decode 三种批次。只有前向。
  • DeepEP 与 DeepGEMM 的执行过程：一个 MoE 层在多卡上的执行顺序。dispatch、grouped GEMM 的 tile 调度、一个 SM 上的流水线、combine 和两个 micro-batch 的重叠，简图、表格和时间线都由 src/sim 的模拟器算出。
  • lm_head 与 NLL Loss（vizflow-page 元素）：同一页用 <vizflow-page> 元素写成，页面只给元素设置属性。

模块与写作说明的检查页

  • scene3d：lm_head 与 NLL Loss：只挂载 3D 场景。
  • scene3d：模块大括号与相机跟随：模块大括号的嵌套与错开，换步骤时相机跟随当前步骤。
  • scene3d：编辑模式：拖动块与标签，复制布局配置。
  • log_softmax 与 nll_loss 小部件：按写作说明独立写出的页面，用来检查说明是否够用。
  • 重叠调度时间轴：没有计算图的步骤条，配合 mountTimeline 的 CPU 与 GPU 时间线和 mountStepPanel 面板。
  • theme：颜色变量与字体。

用构建工具的项目

examples/vite-project/ 是一个独立的 Vite + TypeScript 项目，从 npm 包的构建工具产物引用 vizflow，内容与 lm_head 页面相同。它要在自己的目录里安装和运行，步骤见其中的 README.md。
